This is a way to manage the state of our processes using a single 8-bit variable and bit shifts! We have a varible with uint8_t type 0b0000 0000.The number "0" means that our switch is turned off.The number "1" means that that our switch is turned on (0000 0001).By using bit shifts within a single variable,we eliminate the need for bool variables and optimize our code.In my code we have only 3 switches.This means that if all switches are turned on,our variable looks like (0000 0111).This code provides functions to turn switches on,turn them off,and display all current switch state and also exit function.Tis is a great exercise for getting a feel for microcontroller programming.
